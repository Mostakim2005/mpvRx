FEATURE [5] (LATEST FEEDBACK)

Zero-Bloat Single Root Folder (Delete-Proof & Uninstall-Proof)

Live Room SQLite database, Secure Folder, thumbnails, config, and media hosted directly in a single user-selected folder—no duplicate backup files.

Zero Storage Duplication

📁 Selected Directory: /sdcard/Documents/mpvRx/

By pointing the live Room SQLite database engine directly to the external root folder, mpvRx eliminates the need for separate backup exports. The active database lives permanently in basic storage and is never wiped on uninstallation.

📁 /sdcard/Documents/mpvRx/ 100% Uninstall-Proof
├── 📄 .nomedia (Blocks gallery from indexing private assets)
├── 📁 database/ [LIVE Active Database — Not a Duplicate Backup]
├── 💾 mpvrx.db (Active Room SQLite File)
├── 💾 mpvrx.db-wal (Active Write-Ahead Log)
└── 💾 mpvrx.db-shm (Active Shared Memory)
├── 📁 vault/ (Secure Folder encrypted private videos)
├── 📁 thumbnails/ (16:9 bookmark thumbnail previews)
├── 📁 config/ (PIN verification salt & player preferences)
├── 📁 music/ (Local music tracks with clean metadata filenames)
├── 📁 companion_videos/ (Audio-less & full companion MP4s)
└── 📁 lyrics/ (Dedicated .lrc files)
1. No Duplicate Backups

No secondary copies or zip snapshots. The app reads and writes the live database directly in this folder.

2. Survives App Uninstall

Because Android never deletes public basic storage on uninstall, your entire library and setup remain 100% intact.

3. Zero Storage Bloat

One single file per asset. Companion videos are audio-less to save bandwidth, and audio replacement prevents duplicates.
