FEATURE BLUEPRINT [5]

Security & Persistence: Direct Secure PIN & Persistent Storage

Direct playback challenges for the Secure Folder PIN directly, eliminating double prompts. Moves private files, thumbnails, Room DB backups, and PIN salts to `/sdcard/Documents/mpvRx/` so uninstallation never deletes data.

Uninstall Survival Architecture
🔑 Fix: Single Secure Folder PIN Challenge

Root Cause of Double Prompt: In 3.1.0, direct playback routed through system DeviceCredentialPrompt (phone lock PIN) while the vault used its own internal password/PIN.

Solution: Check if SecureFolderRepository is already unlocked. If not, prompt with the Secure Folder PIN directly, completely eliminating duplicate device PIN requests.

🛡️ Fix: Persistent Storage at `/sdcard/Documents/mpvRx/`

Root Cause of Data Loss: Storing in context.filesDir causes Android to destroy private videos, database, and settings on app uninstallation.

Solution: Store in /sdcard/Documents/mpvRx/ with .nomedia. Holds vault media, thumbnails, Room SQLite snapshots, and salted PIN verifiers across uninstalls.
