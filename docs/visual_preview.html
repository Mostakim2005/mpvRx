FEATURE BLUEPRINT [5]

Security & Persistence: Secure Folder PIN Gate & Uninstall Survival

Fixes double PIN prompts by querying Secure Folder's own credentials. Establishes persistent vault storage so uninstalling the app never destroys private media.

Architecture Solution
🔑 Fix: Single Secure Folder PIN Challenge

Root Cause of Double Prompt: In 3.1.0, direct playback used system DeviceCredentialPrompt (phone lock PIN) while the vault used its own internal password/PIN.

Solution: Unify the challenge to check if SecureFolderRepository is unlocked. If not, challenge with the Secure Folder PIN directly, completely eliminating double prompts.

🛡️ Fix: Vault Storage Persistence (Survive Uninstall)

Root Cause of Data Loss: Storing vault files in context.filesDir causes Android to wipe all private videos and SQLite databases on app uninstallation.

Solution: Store vault media and database backups in persistent app-external directory (e.g. /Android/media/app.gyrolet.mpvrx/vault/ or user-selected SAF folder with .nomedia).
