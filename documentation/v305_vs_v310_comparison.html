COMPARISON [7]

URI Path Normalization: java.net.URI Crash (3.1.0) vs. Pure String (3.1.1)

Location: PlaybackModels.kt:normalizeLocalPath

✅ Solved in v3.1.1

In v3.1.0, URI(null, null, path, null).normalize().path returned null for Bengali/Unicode filenames (e.g. "Gmail কাজ করার নিয়ম.mp4") and opaque IDs. In Kotlin, runCatching treated null as success, and calling null.trim() crashed Room Flow background threads with NullPointerException.

In v3.1.1, this was replaced with pure-string segment normalization that safely strips schemes, resolves traversal segments, and never returns null or throws.
